# Lux RSS

Daily aggregator for Luxembourg news, business, government, and events. Pulls from public RSS feeds, stores in Postgres, serves a single-page UI with category tabs.

## Stack

- Next.js 15 (App Router) + React 19 + Tailwind
- Drizzle ORM + Postgres (Render managed)
- `rss-parser` for ingestion
- Render Web Service + Render Cron Job

## Layout

```
app/                Next.js routes (UI + /api/refresh)
lib/db/             Drizzle schema + pg client
lib/sources.ts      Feed registry (edit to add/remove sources)
lib/fetch-feeds.ts  Shared ingestion logic
scripts/fetch.ts    Cron entrypoint (Render Cron Job runs this)
render.yaml         Render Blueprint (web + cron + DB)
```

## Deploy to Render

1. Push this repo to GitHub.
2. In the Render dashboard: **New → Blueprint** → select the repo.
3. Render reads `render.yaml` and provisions:
   - Postgres `lux-rss-db` (free tier)
   - Web service `lux-rss-web` (free tier)
   - Cron job `lux-rss-cron` (starter — Render Cron is not available on the free plan)
4. Wait for the web service to deploy (this runs `db:push` during build, creating the schema).
5. Trigger the cron once manually from its Render dashboard to populate data immediately. Subsequent runs happen daily at **06:00 UTC** (≈ 7–8am Luxembourg, depending on DST).

## Cost note

Render Cron Jobs require a paid instance (~$1/mo for `starter`). If you want to stay fully free, delete the `cron` service from `render.yaml` and use a free external scheduler (e.g. cron-job.org, GitHub Actions) to POST to:

```
POST https://<your-web-service>.onrender.com/api/refresh
Authorization: Bearer <REFRESH_TOKEN>
```

The `REFRESH_TOKEN` is auto-generated by Render — find it under the web service's Environment tab. Note that free Render web services sleep after 15min idle; the first refresh request after sleep will cold-start the service (~30s) before running.

## Local development

```bash
cp .env.example .env       # fill in DATABASE_URL (local or remote Postgres)
npm install
npm run db:push            # create tables
npm run fetch              # populate feeds once
npm run dev                # serve on http://localhost:3000
```

## Adding / removing sources

Edit `lib/sources.ts`. Each entry: `{ name, url, category, lang }`. Categories are `news | business | government | events`. The next cron run upserts new entries.

## Source feed reliability

Luxembourg RSS endpoints are not always documented. The fetch job is fault-tolerant: if a feed returns 404 or invalid XML, the error is recorded against the source row and shown at the bottom of the UI under "Source errors" — but other feeds continue to ingest. If you see a source consistently failing, find its current RSS URL and update `lib/sources.ts`.

## Data retention

`scripts/fetch.ts` prunes items older than 30 days on each run.
